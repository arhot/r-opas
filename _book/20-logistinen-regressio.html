Logistinen regressioanalyysi

Logistinen regressio ennustaa lineaarisen regression tapaan selitettävää tekijää yhden tai useamman selittäjän avulla, mutta selitettävä tekijä on nyt kaksiluokkainen - esimerkiksi kyllä/ei, tai kuuluuko johonkin ryhmään vai ei. Malli on muuten samanlainen kuin lineaarinen regressio, mutta sen tuloksena saatavat kertoimet kuvaavat vetosuhteita (odds ratio), eivät suoraan selitettävän tekijän muutosta.

Kaksiluokkaisen selitettävän tekijän muodostaminen

Jos aineistossa on valmiiksi kaksiluokkainen muuttuja, riittää merkitä se luokitelluksi as_factor()-komennolla. Jos taas selitettävä tekijä on alun perin jatkuva, sen voi jakaa kahtia cut()-komennolla - otetaan nyt esimerkiksi onnellisuutta mittaava muuttuja C1, ja muodostetaan siitä kaksiluokkainen muuttuja, jossa arvot 0-8 ovat “Ei kovin onnellinen” ja arvot 9-10 “Onnellinen”.

ESS2023 <- ESS2023 |>
  mutate(Onnellinen = cut(C1,
                           breaks = c(-Inf, 8, Inf),
                           labels = c("Ei kovin onnellinen", "Onnellinen")))

ESS2023 |> tabyl(Onnellinen) |> adorn_pct_formatting(digits = 1) |> as_tibble()
# A tibble: 3 × 4
  Onnellinen              n percent valid_percent
  <fct>               <dbl> <chr>   <chr>        
1 Ei kovin onnellinen   889 56.9%   57.0%        
2 Onnellinen            671 42.9%   43.0%        
3 <NA>                    3 0.2%    -

Kannattaa aina tarkastaa, että selitettävässä tekijässä on täsmälleen kaksi luokkaa (puuttuvien tietojen lisäksi).

Muuttujien valmistelu

Käytetään selittäjinä jo tuttuja muuttujia: ikä, sukupuoli ja koulutusaste.

ESS2023 <- ESS2023 |>
  mutate(
    Ikä = 2023 - Syntymävuosi,
    Sukupuoli = as_factor(Sukupuoli),
    Koulutusaste = cut(F15,
                        breaks = c(0, 3, 8, 15),
                        labels = c("1. aste", "2. aste", "3. aste tai korkeampi"))
  )

Logistinen regressiomalli

Malli tehdään glm()-komennolla (generalized linear model), joka toimii lm():n tavoin, mutta lisäargumentilla family kerrotaan mallin tarkempi tyyppi - logistiseen regressioon family = binomial(link = "logit").

Rakennetaan malli hierarkkisesti lisäämällä selittäjiä yksi kerrallaan, ja viimeiseen malliin vielä iän ja sukupuolen yhdysvaikutus.

m1 <- ESS2023 |> glm(Onnellinen ~ Ikä, data = _, family = binomial(link = "logit"))
m2 <- ESS2023 |> glm(Onnellinen ~ Ikä + Sukupuoli, data = _, family = binomial(link = "logit"))
m3 <- ESS2023 |> glm(Onnellinen ~ Ikä + Sukupuoli + Koulutusaste, data = _, family = binomial(link = "logit"))
m4 <- ESS2023 |> glm(Onnellinen ~ Ikä * Sukupuoli + Koulutusaste, data = _, family = binomial(link = "logit"))

Vetosuhteet

summary() antaa mallin kertoimet logaritmisella asteikolla ja niitä on hankala tulkita suoraan. Vetosuhteet (ja niiden luottamusvälit) saa tidy()-komennolla asettamalla exponentiate = TRUE.

m1 |> tidy(exponentiate = TRUE, conf.int = TRUE) |>
  mutate(across(where(is.numeric), ~ round_half_up(.x, 2)))

Vetosuhde alle yhden tarkoittaa, että veto pienenee selittäjän kasvaessa (tai verrattuna vertailuryhmään), ja yli yhden, että veto kasvaa. Esimerkiksi jos iän vetosuhde on 1.02, ikävuoden lisäys kasvattaa vetoa 2 %:lla.

Tulosten visualisointi

Vetosuhteita on vaikea hahmottaa suoraan, joten tulkinta kannattaa tehdä kuvion avulla. augment()-komento laskee mallin ennustamat todennäköisyydet - type.predict = "response" varmistaa, että ne ovat prosentteina (0-1) eivätkä logaritmisella asteikolla.

m4tulokset <- augment(m4, type.predict = "response")

ggplot(m4tulokset, aes(x = Ikä, y = .fitted, colour = Sukupuoli)) +
  geom_point() +
  labs(y = "Ennustettu todennäköisyys") +
  coord_cartesian(ylim = c(0, 1)) +
  theme_minimal()

Jos mallissa on enemmän selittäjiä kuin kuvioon mahtuu, ennusteet eivät enää näytä yhtä systemaattisilta - kuvaan valitsematon selittäjä (tässä koulutusaste) vaikuttaa silti ennusteeseen taustalla.

Marginaalivaikutukset

Vetosuhde kertoo vedon suhteellisen muutoksen, mutta ei suoraan sitä, kuinka paljon ennustettu todennäköisyys muuttuu - se riippuu siitä, mistä kohtaa todennäköisyysasteikkoa lähdetään. marginaleffects-paketin avg_slopes() laskee keskimääräisen marginaalivaikutuksen (average marginal effect): kuinka monta prosenttiyksikköä ennustettu todennäköisyys keskimäärin muuttuu, kun selittäjä kasvaa yhdellä yksiköllä (tai luokitellulla selittäjällä, kun siirrytään vertailuryhmästä toiseen).

m4 |> avg_slopes(variables = "Ikä")

 Estimate Std. Error    z Pr(>|z|)    S   2.5 %  97.5 %
  0.00281   0.000646 4.35   <0.001 16.2 0.00155 0.00408

Term: Ikä
Type: response
Comparison: dY/dX

Tulos on suoraan prosenttiyksikköinä todennäköisyysasteikolla, mikä on usein helpompi viestiä kuin vetosuhde.

Luokitellulle selittäjälle vastaava luku saadaan samalla komennolla, tai ennustettuina todennäköisyyksinä ryhmittäin avg_predictions()-komennolla, kun muut selittäjät pidetään vakioina:

m4 |> avg_predictions(by = "Sukupuoli")

 Sukupuoli Estimate Std. Error    z Pr(>|z|)     S 2.5 % 97.5 %
    Mies      0.396     0.0176 22.5   <0.001 371.3 0.362  0.431
    Nainen    0.463     0.0176 26.3   <0.001 505.3 0.428  0.497

Type: response

Myös kuvion pystyy tekemään suoraan mallista plot_predictions()-komennolla ilman augment()-välivaihetta:

plot_predictions(m4, condition = c("Ikä", "Sukupuoli")) +
  theme_minimal()
