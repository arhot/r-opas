Osa 2: Harjoitustehtävät

Muuttujien muuntaminen ja tarkistaminen

Seuraavissa tehtävissä käytetään oppaan yhteistä ESS 2023 -aineistoa. Tehtävät kertaavat muuttujamuunnoksia ja kuvailevia analyysejä.

Koulutusluokkien ryhmittely

Muodosta muuttujasta F15 kolmiluokkainen Koulutusaste yhdistämällä alkuperäiset luokat 1–3, 4–8 ja 9–14. Tarkista luokkien vastaajamäärät. Aineistossa arvo 5555 tarkoittaa vastausta “Jokin muu”, joten jätä se luokittelun ulkopuolelle.

ESS2023 <- ESS2023 |>
    mutate(Koulutusaste = ...)

ESS2023 |> count(Koulutusaste)
HuomautusMalliratkaisu 
ESS2023 <- ESS2023 |>
    mutate(
        F15_luokka = na_if(as.numeric(F15), 5555),
        Koulutusaste = cut(
            F15_luokka,
            breaks = c(0, 3, 8, Inf),
            labels = c("Peruskoulu tai alempi", "Keskiaste", "Korkea-aste")
        )
    )

ESS2023 |> count(Koulutusaste)
# A tibble: 4 × 2
  Koulutusaste              n
  <fct>                 <int>
1 Peruskoulu tai alempi   253
2 Keskiaste               715
3 Korkea-aste             593
4 <NA>                      2

Tarkistuksessa pitäisi näkyä kolme koottua koulutusastetta sekä puuttuvien määrä. “Jokin muu” jää luokittelun ulkopuolelle, koska se ei kuulu alkuperäiseen järjestykseen 1–14.

Puolueen kannatus ja pienet ryhmät

Muuta B14 luokitelluksi muuttujaksi, kokoa harvinaisimmat vastaukset yhteen ja järjestä luokat yleisimmästä harvinaisimpaan. Kuinka monta vastausta jää “Muu puolue” -luokkaan?

ESS2023 <- ESS2023 |>
    mutate(Puolue = ...)

ESS2023 |> count(Puolue, sort = TRUE)
HuomautusMalliratkaisu 
ESS2023 <- ESS2023 |>
    mutate(
        Puolue = B14 |>
            as_factor() |>
            fct_lump(n = 8, other_level = "Muu puolue") |>
            fct_infreq()
    )

ESS2023 |> count(Puolue, sort = TRUE)
# A tibble: 10 × 2
   Puolue                                  n
   <fct>                               <int>
 1 <NA>                                  386
 2 Suomen Sosialidemokraattinen Puolue   293
 3 Kansallinen Kokoomus                  257
 4 Perussuomalaiset                      176
 5 Vihreä liitto                         117
 6 Suomen Keskusta                       106
 7 Vasemmistoliitto                       73
 8 Suomen ruotsalainen kansanpuolue       58
 9 Suomen Kristillisdemokraatit           56
10 Muu puolue                             41

Ratkaisu säilyttää kahdeksan yleisintä puoluetta ja kokoaa loput yhteen. Puuttuvat vastaukset pysyvät puuttuvina.

Ristiintaulukko

Tee koulutusasteen ja sukupuolen ristiintaulukko. Laske osuudet sukupuoliryhmien sisällä: kuinka koulutusasteet jakautuvat kussakin ryhmässä?

ESS2023 |>
    tabyl(Koulutusaste, Sukupuoli, show_na = FALSE) |>
    adorn_percentages("col") |>
    adorn_pct_formatting(digits = 1) |>
    as_tibble()
HuomautusMalliratkaisu

Koulutusaste muodostettiin ensimmäisessä tehtävässä. Muunna sukupuoli luokitelluksi ennen taulukointia:

ESS2023 <- ESS2023 |>
    mutate(Sukupuoli = as_factor(Sukupuoli))

ESS2023 |>
    tabyl(Koulutusaste, Sukupuoli, show_na = FALSE) |>
    adorn_percentages("col") |>
    adorn_pct_formatting(digits = 1) |>
    as_tibble()
# A tibble: 3 × 3
  Koulutusaste          Mies  Nainen
  <fct>                 <chr> <chr> 
1 Peruskoulu tai alempi 16.4% 16.0% 
2 Keskiaste             49.7% 42.0% 
3 Korkea-aste           33.9% 41.9%

Jokaisen sukupuolisarakkeen prosenttien summa on 100 % lukuun ottamatta pyöristyseroa. Sarakeprosentit vastaavat kysymykseen koulutusasteiden jakaumasta sukupuoliryhmittäin.

Painotettu keskiarvo

ESS-aineiston analyysipaino_suomi korjaa aineiston painotusta. Laske onnellisuuden (C1) painottamaton ja analyysipainolla painotettu keskiarvo. Vertaa lukuja ja pohdi, muuttaako painotus arviota paljon.

ESS2023 |>
    summarise(
        Painottamaton = ...,
        Painotettu = ...
    )
HuomautusMalliratkaisu 
ESS2023 |>
    summarise(
        Painottamaton = mean(C1, na.rm = TRUE),
        Painotettu = weighted.mean(C1, analyysipaino_suomi, na.rm = TRUE)
    ) |>
    mutate(across(where(is.numeric), ~ round(.x, 2)))
# A tibble: 1 × 2
  Painottamaton Painotettu
          <dbl>      <dbl>
1          8.07       8.04

Tässä aineistossa painottamaton keskiarvo on noin 8,07 ja painotettu noin 8,04. Yksinkertainen painotus näyttää piste-estimaatin eron, mutta tämä lasku ei yksin huomioi monimutkaisen otanta-asetelman vaikutusta keskivirheisiin. Lue lisää painottamisesta.
