Osa 4: Harjoitustehtävät

Tehtävissä käytetään regressioanalyysin, varianssianalyysin, faktorianalyysin ja logistisen regression menetelmiä. Jokainen malliratkaisu toimii itsenäisesti tämän sivun alussa ladatulla ESS-aineistolla.

Faktorianalyysi

ESS-aineiston H-alkuiset muuttujat mittaavat Schwartzin perusarvoja. Tee niille neljän faktorin suurimman uskottavuuden faktorianalyysi varimax-rotaatiolla. Tulosta vähintään 0,30:n lataukset ja nimeä faktorit niiden latautuvien väittämien sisällön perusteella.

faktorianalyysi <- fa(
    ESS2023 |> select(starts_with("H")),
    nfactors = 4,
    fm = "ml",
    rotate = "varimax"
)

faktorianalyysi |> fa.sort() |> print(cut = 0.3)

Lineaarinen regressio

Tarkastele, miten koulutusaste ja sukupuoli liittyvät onnellisuuteen (C1). Muodosta malli, jossa molemmat ovat selittäjinä. Muodosta koulutusaste ryhmittelemällä F15-muuttujan luokat 1–3, 4–8 ja 9–14. Arvo 5555 tarkoittaa “Jokin muu” -vastausta, joten jätä se pois. Tulosta kertoimet luottamusväleineen ja tulkitse koulutusryhmien kertoimet vertailuryhmään nähden.

malliaineisto <- ESS2023 |>
    mutate(
        Koulutusaste = ...,
        Sukupuoli = as_factor(Sukupuoli)
    )

malli <- lm(C1 ~ Koulutusaste + Sukupuoli, data = malliaineisto)
tidy(malli, conf.int = TRUE)

malliaineisto |>

Logistinen regressio

Muodosta muuttujasta C1 kaksiluokkainen onnellisuusmuuttuja: arvot 0–8 ovat “Ei kovin onnellinen” ja 9–10 “Onnellinen”. Sovita logistinen regressiomalli sukupuolen ja koulutusasteen avulla. Tulosta kertoimet vetosuhteina luottamusväleineen ja tulkitse, mitä vetosuhde yli yhden tarkoittaa.

malliaineisto <- ESS2023 |>
    mutate(
        Onnellinen = ...,
        Sukupuoli = as_factor(Sukupuoli),
        Koulutusaste = ...
    )

malli <- glm(
    Onnellinen ~ Sukupuoli + Koulutusaste,
    data = malliaineisto,
    family = binomial(link = "logit")
)

tidy(malli, exponentiate = TRUE, conf.int = TRUE)

## Ryhmäkeskiarvot ja yhdysvaikutus

Muodosta koulutusvuosista samat kolme koulutusastetta kuin osan 2 harjoituksessa ja tarkastele onnellisuuden keskiarvoja sukupuolen ja koulutusasteen mukaan. Sovita tämän jälkeen malli, jossa on myös sukupuolen ja koulutusasteen yhdysvaikutus. Vertaa tuloksia [ANOVA-luvun](18-anova.qmd) tapaan.

    mutate(
        Sukupuoli = as_factor(Sukupuoli),
